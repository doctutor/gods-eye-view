# Sample camera paths

Camera paths for the bridge, made on the PC with `npm run msfs:path`.
They are data, kept so a fresh render machine can fetch one without a
file transfer (`irm` from the fork). Personal fork only.

- `baltimore.json`: Inner Harbor north to Druid Hill Park, 4.45 km in
  111 s at 40 m/s, 150 m above Earth Engine elevation, 30 fps, 3,339 samples.
